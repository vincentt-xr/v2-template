# CLAUDE.md

Claude Code reads this file automatically. It is a pointer and holds nothing of its own.

The agent contract for this project — the dev loop, the platform commands, waiting for the
phone, what to edit and what to leave alone — is **[AGENTS.md](./AGENTS.md)**. Read it first.

There are two grounding files, and nothing merges them. Read both when you begin a
scene, not before:

- **[GROUNDING.md](./GROUNDING.md)** — this template's local helpers (capture,
  overlay, sprite, gesture), project notes, and patterns.
- **`node_modules/@vincentt-xr/sdk/GROUNDING.md`** — the SDK API reference: every
  component, hook, and prop. The larger of the two.
